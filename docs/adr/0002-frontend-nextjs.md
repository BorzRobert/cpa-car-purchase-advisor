# ADR 0002 — Frontend: rămâne Next.js

- **Status:** acceptat (2026-11-11)
- **Decizie:** păstrăm Next.js (React + TypeScript), folosit exclusiv ca UI, fără Route Handlers.
- **Motiv:** cost zero de rescriere, deploy-ul pe Vercel este deja documentat.
- **Alternative respinse:** rescriere ca SPA Vite.
